- [Get sandbox details](https://docs.gmicloud.ai/api-reference/sandbox/get-sandbox-details.md): Returns sandbox details. Instances in the terminal failure state (`failed`) remain readable, with the failure reason in `failure`; deleted or expired instances return 404.
- [Delete (kill) a sandbox](https://docs.gmicloud.ai/api-reference/sandbox/delete-kill-a-sandbox.md): Accepts the deletion. A 202 response means the deletion intent has been persisted and the instance enters `deleting`; it only becomes `deleted` after the backing resources are confirmed released. - [Update sandbox metadata](https://docs.gmicloud.ai/api-reference/sandbox/update-sandbox-metadata.md): Replaces the customer-defined metadata as a whole — no per-key merging; passing an empty object clears it. There are no mutable fields other than `metadata`. This operation does not take the lifecycle lock, so it works in any visible state.
- [Connect to a sandbox](https://docs.gmicloud.ai/api-reference/sandbox/connect-to-a-sandbox.md): Connects to a running sandbox and returns its data-plane connection info (domain and access token). When `timeout` is provided and greater than 0, the call also extends the sandbox's lifetime (extend-only, never shortens). Returns 409 if the instance is not running.
- [Set sandbox timeout](https://docs.gmicloud.ai/api-reference/sandbox/set-sandbox-timeout.md): Resets the time-to-live relative to the current time. When `timeout` is omitted or is 0 or less, 300 seconds is used. Only allowed while `running`; any other state returns 409.
- [Execute a command in a sandbox](https://docs.gmicloud.ai/api-reference/sandbox-exec/execute-a-command-in-a-sandbox.md): Starts an asynchronous shell execution in the sandbox. The request body keeps the `action=exec` and `parameters` shape used by the runtime contract. - [Cancel a sandbox execution](https://docs.gmicloud.ai/api-reference/sandbox-exec/cancel-a-sandbox-execution.md): Requests cancellation of a non-terminal execution. Cancellation is idempotent: repeated calls return the terminal canceled result after the provider confirms it.
- [Download a sandbox file](https://docs.gmicloud.ai/api-reference/sandbox-files/download-a-sandbox-file.md): Reads a single file inside the sandbox by absolute path; the response body is the raw byte stream.

Not supported in every IDC; IDCs without rebuild support reject it with 422.
