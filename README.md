GMI Cloud is a GPU cloud and AI inference provider offering the Inference Engine (OpenAI-compatible LLM, image and video model APIs at api.gmi-serving.com), the Cluster Engine for GPU containers, bare-metal and VPC infrastructure, and GMI Sandbox for isolated code execution. Its control-plane APIs are served from console.gmicloud.ai and documented at docs.gmicloud.ai.

**Areas:** Company · Artificial Intelligence · Inference · GPU Cloud · LLM · Model Routing · Sandbox · Infrastructure
